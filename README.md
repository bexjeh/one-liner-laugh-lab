A one-line excuse from a robot vacuum after eating a sock — deadpan, bureaucratic, and (allegedly) legally sound.

## Run it

```sh
python3 main.py
```

Writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./entry.txt` if unset).
